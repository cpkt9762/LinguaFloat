## 模块职责

### AppShell
- 菜单栏图标与状态管理
- 全局窗口生命周期
- 应用启动与退出
- 系统事件监听入口

### UI Layer
- **TranslateView**: 翻译结果浮层，支持复制/关闭
- **SettingsView**: 设置页（通用/高级/快捷键/关于）
- **PermissionView**: 权限引导与状态展示

### Domain Layer
- **TranslationService**: 翻译调度、缓存、错误处理
- **TextExtractor**: 选区获取、剪贴板复制与恢复、AX 读取
- **LanguageDetector**: 语言自动检测与规则匹配
- **TriggerManager**: 快捷键与三连空格触发管理

### Provider Layer
- **TranslationProvider**: 统一协议，定义翻译能力
- **GoogleWebProvider**: WKWebView 打开 Google Translate
- **OpenAIProvider**: OpenAI API 翻译（阶段3）
- **ClaudeProvider**: Claude API 翻译（阶段3）
- **DeepSeekProvider**: DeepSeek API 翻译（阶段3）

### Support Layer
- **KeychainManager**: API Key 安全存储
- **SettingsStore**: 用户配置持久化（UserDefaults）
- **HistoryStore**: 翻译历史存储（CoreData/SwiftData）
- **PermissionManager**: 权限状态检测与引导
- **ClipboardManager**: 剪贴板保护与恢复

## 数据流

```
用户触发（快捷键/三连空格）
        │
        ▼
  TriggerManager
        │
        ▼
  TextExtractor ──→ 获取选中文本/输入框内容
        │
        ▼
  TranslationService
        │
        ├──→ LanguageDetector（检测语言）
        │
        ├──→ Provider（调用翻译）
        │
        ▼
  TranslateView ──→ 显示结果
```

## 依赖方向

- UI → Domain → Provider → Support
- 上层依赖下层，下层不依赖上层
- Provider 之间互不依赖
