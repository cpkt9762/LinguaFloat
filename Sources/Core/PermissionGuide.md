# LinguaFloat 权限策略设计

## 权限类型

### 1. 辅助功能 (Accessibility)
- **用途**: 读取选中文本、获取输入框内容
- **请求时机**: 仅在启用"三连空格触发"功能时
- **系统路径**: 系统设置 > 隐私与安全性 > 辅助功能

### 2. 输入监控 (Input Monitoring)
- **用途**: 监听全局键盘事件（检测三连空格）
- **请求时机**: 仅在启用"三连空格触发"功能时
- **系统路径**: 系统设置 > 隐私与安全性 > 输入监控

## 权限请求策略

### MVP 阶段
- **默认不请求任何权限**
- 用户启用"三连空格"功能时，引导授权
- 用户可以只使用"快捷键翻译"功能，无需任何权限

### 权限请求流程
1. 用户打开设置 > 启用"三连空格触发"
2. 检测当前权限状态
3. 如未授权，显示引导弹窗
4. 引导用户跳转系统设置授权
5. 授权后自动启动监听

## 降级策略

### 无辅助功能权限
- 三连空格触发：需要先选中文本
- 快捷键翻译：使用剪贴板复制方式获取文本

### 无输入监控权限
- 三连空格功能不可用
- 提示用户只能使用快捷键方式

### 两者都无
- 仅支持菜单栏手动输入翻译
- 仅支持快捷键+剪贴板方式

## 用户引导文案

### 辅助功能
```
LinguaFloat 需要「辅助功能」权限来读取您选中的文本。

此权限仅用于获取当前选区内容，不会收集或上传任何其他信息。

点击「前往设置」，在列表中找到 LinguaFloat 并勾选。
```

### 输入监控
```
LinguaFloat 需要「输入监控」权限来检测三连空格触发。

此权限仅用于识别空格键连按，不会记录您的任何输入内容。

点击「前往设置」，在列表中找到 LinguaFloat 并勾选。
```


## 隐私声明要点
- 文本仅在用户主动触发时获取
- 文本发送到翻译服务（Google Translate）
- 本地不存储原文（历史记录可选）
- 不收集任何用户输入日志
